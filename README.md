# 室内解密 (Indoor Escape Room)

这是一个使用 Unity 制作的室内解密游戏。玩家扮演一个小孩，在家长外出的时候，需要在房间里寻找线索，解开谜题，最终打开电脑并输入密码。

## 项目结构

-   `Assets/Scenes`: 包含游戏的主要场景。
-   `Assets/c#`: 包含游戏的所有 C# 脚本。
-   `ProjectSettings`: Unity 项目设置。

## 脚本功能

以下是 `Assets/c#` 文件夹中主要脚本的功能简介：

-   `main UI.cs`: 管理主菜单的用户界面，包括开始游戏、退出游戏和设置菜单的逻辑。

-   `move.cs`: 控制玩家角色的移动和视角。它处理键盘输入以实现移动，并使用鼠标输入来旋转相机。

-   `computer.cs`: 实现与游戏中的电脑的交互。玩家靠近电脑时可以按“Z”键打开电脑界面，需要输入正确的密码才能进入下一步。

-   `door.cs`: 控制门的开关和锁定状态。门可以被锁定，需要玩家拥有特定的钥匙才能解锁。玩家靠近门时按“F”键可以尝试开门。

-   `opendoor.cs`: 另一个与门和钥匙相关的脚本，允许玩家拾取钥匙。

-   `obtainitem.cs`: 允许玩家拾取在场景中的道具（例如钥匙）。当玩家靠近并注视道具时，可以按“F”键拾取。

-   `tasksystem.cs`: 管理游戏中的任务和玩家的道具库存。它会跟踪玩家是否拥有特定的钥匙，并可以更新任务状态。

-   `tasklist.cs`: 在屏幕上显示任务列表。玩家可以按“Tab”键查看当前的任务。

-   `code.cs`: 当特定的门打开后，玩家可以与一个代码面板进行交互。

## 如何游玩

1.  使用 `W`, `A`, `S`, `D` 键移动。
2.  使用鼠标来环顾四周。
3.  靠近可交互的物体（如门、电脑、道具）时，屏幕上会出现提示。
4.  按 `F` 键与物体交互（开门、拾取道具）。
5.  按 `Z` 键与电脑交互。
6.  长按 `Tab` 键查看任务列表。
7.  探索环境，找到线索，解决谜题，最终逃出房间。
